# Assessment Could Demonstrate Learning Gains, but What is Required for It to Do So?

**Author:** David Boud
**Year:** 2018
**Source type:** article
**Raw file:** [Boud 2018.pdf](../../raw/articles/Boud%202018.pdf)

## Summary

An opinion piece arguing that a ready source of data to investigate learning gain is that generated normally through student assessment. Boud argues that such data cannot currently be used for this purpose because assessment is not set up to inform us about student learning, and calls for the refreshment of assessment thinking to bring it in line with thinking about standards.

## Key Claims

- The most readily available measure of learning gain is existing data from student assessments, but we can't use assessment as it is practiced currently because ironically it is not set up to inform us about student learning (p. 54).
- If assessment was really a process of judging performance against learning outcomes within a framework of declared standards, then there would not be a problem (p. 54).
- The difficulty is not that higher education assessment is technically inadequate, though that might also be true, but that it is rooted in an unclear notion of what assessment should seek to do and how it should seek to do it (p. 54).
- Higher education globally has moved from an era of elite intake and stability of cohorts in which assessment was used to judge students against each other, to one that is slowly becoming outcomes-based, using explicit standards against which each student is judged (p. 54).
- The old norm-based regime could not, in principle, ensure that academic standards were being met and that the standards exhibited in one discipline in one university were equivalent to those in the same discipline in another university or another country (p. 54-55).
- Although the new regime has been accepted in principle in most institutions, it has not yet translated into everyday assessment practice (p. 55).
- Common characteristics of assessment today: marks for a given unit are not indicators of each learning outcome; marks are aggregated across different learning outcomes; pass marks are set in arbitrary ways; pass marks are determined within a disciplinary culture with no calibration across units; students who do well on some outcomes are compensated for poor performance on others; re-sits provide marks hard to match with earlier tests; the standards to reach a pass may be higher in later course units (p. 55).
- Increases in marks from one unit to another or one year to another cannot be taken as a gain as there is no common metric or frame of reference (p. 55).
- The most problematic feature of current marking practices is that it is not possible to associate any reported mark with what a student can or cannot do; marks act as obscuring devices (p. 55).
- There is a much more urgent task for assessment reform: to make marking and grading fit for the key purpose of indicating what a student has achieved (p. 55).
- A reform process could start with: all assessments made in relation to explicit program learning outcomes against specific standards and criteria; standards and criteria consistent and calibrated across all units; the same program learning outcomes judged at different levels across different units and years (p. 55).
- For the purposes of identification of learning gains: assessments need to be directly related to explicitly articulated course/program learning outcomes, not unit or module outcomes; no aggregation of marks across different learning outcomes should be permitted; marking rubrics at different levels need overlap of items to enable standards to be tracked across a program (p. 56).
- If this were done, we could produce for each student a track of learning achieved for each course/program learning outcome: an obvious measure of learning gain (p. 56).
