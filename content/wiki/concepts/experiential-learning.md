# Experiential Learning

## Definition

Learning that emphasizes the process by which knowledge is created through experience. Kolb's experiential learning theory structures the learning process in a four-stage learning circle containing the abilities of Concrete Experience, Reflective Observation, Abstract Conceptualization, and Active Experimentation. Every person's learning style is a component of these four learning abilities.
